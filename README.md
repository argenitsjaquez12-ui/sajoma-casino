# SAJOMA CASINO v5 FINAL

Versión final de entretenimiento con monedas virtuales.

Incluye:
- Splash y branding SAJOMA CASINO
- Diseño negro/dorado
- Perfil y nombre de jugador
- Guardado local con SharedPreferences
- Saldo e historial persistentes
- Tragamonedas, ruleta, blackjack y póker virtual
- Bono diario
- Nivel y XP
- Misiones
- Torneo virtual semanal (clasificación conceptual por XP)
- Navegación funcional
- Android + iPhone mediante Flutter

IMPORTANTE: esta versión NO procesa dinero real, depósitos, retiros ni apuestas con dinero real.

## Ejecutar
flutter pub get
flutter run

## Generar Android
flutter build apk --release

## Generar iPhone
flutter build ios --release
(la compilación/distribución de iOS requiere macOS/Xcode y una cuenta Apple adecuada.)
